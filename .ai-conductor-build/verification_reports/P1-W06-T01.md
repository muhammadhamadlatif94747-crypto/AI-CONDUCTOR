# VG-P1-W06-T01 — Outbox / Intent Mechanism

**Task:** P1-W06-T01 — Outbox/intent mechanism so multi-record transitions
are durable via recorded intent (Blueprint Invariant 15, Section 20;
Phase Manifest §5.5).

**Status:** ACCEPTED

## Implementation
`PROJECT/crates/conductor-kernel/src/outbox.rs`, built on the P1-W05
`persist::AtomicStore` primitive (inherits atomic-write + single-writer
serialization for free).

- `Outbox::begin_intent(id, kind, step_names)` — durably records an
  intent and every step it will perform, all `completed = false`,
  BEFORE any effect runs.
- `Outbox::mark_step_complete(id, step_name)` — durably marks one step
  done after its effect has actually run; idempotent to call again on an
  already-complete step (needed for replay safety).
- `Outbox::retire_intent(id)` — removes a fully-completed intent;
  refuses (fails closed) to retire one with incomplete steps.
- `Outbox::pending()` — recovery entry point: every intent not yet fully
  complete, in deterministic order, each carrying exactly which steps
  are outstanding.

## Tests (10 new, all passing)
- `begin_intent_records_all_steps_as_pending`
- `duplicate_intent_id_is_rejected_not_silently_merged`
- `happy_path_all_steps_complete_then_retire`
- `retiring_an_incomplete_intent_is_refused`
- `marking_an_already_complete_step_again_is_a_safe_no_op`
- `unknown_intent_and_unknown_step_are_reported_not_silently_ignored`
- `interruption_mid_outbox_is_recovered_and_replayed_exactly_once` —
  **core VG-P1-W06-T01 proof.** Drops an `Outbox` handle after 1 of 3
  steps is marked complete (no in-memory state carried forward), opens a
  fresh `Outbox` over the same file exactly as a process restart would,
  and asserts recovery reports precisely the 2 unfinished steps — not
  re-running the completed one, not skipping an unfinished one. Replays
  them and confirms the intent reaches `Completed`.
- `interruption_before_any_step_runs_still_recovers_full_intent` — crash
  immediately after `begin_intent`, zero steps ever run; recovery still
  sees the whole intent.
- `multiple_concurrent_intents_are_tracked_independently`
- `pending_on_a_store_that_has_never_been_written_is_empty_not_an_error`
